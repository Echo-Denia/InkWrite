# 手写字体工程 · 依赖安装

本机：Win11 + conda 环境 `moreother`（用 `conda run` 调用）+ NVIDIA GPU。

## 一、Python 包（推荐：先激活环境再装）

```bat
conda activate moreother
uv pip install --index-url https://pypi.tuna.tsinghua.edu.cn/simple -r requirements.txt
```

uv 会识别当前激活的 conda 环境（`CONDA_PREFIX`），包直接装进 `moreother`。

### 备选 A：不激活，用 conda run

```bat
conda run -n moreother --no-capture-output uv pip install ^
  --python "%USERPROFILE%\anaconda3\envs\moreother\python.exe" ^
  --index-url https://pypi.tuna.tsinghua.edu.cn/simple ^
  -r requirements.txt
```

> `--no-capture-output` 必须加，否则 `conda run` 会把安装进度吞掉，看起来像卡死。
> 上面 anaconda3 若你装的是 miniconda / miniforge，改成对应目录名。

### 备选 B：用环境变量指定源

```bat
set UV_INDEX_URL=https://pypi.tuna.tsinghua.edu.cn/simple
conda run -n moreother --no-capture-output uv pip install -r requirements.txt
```

### 备选 C：换其他国内源

```
--index-url https://mirrors.aliyun.com/pypi/simple
--index-url https://mirrors.cloud.tencent.com/pypi/simple
```

### 装完自检

```bat
conda run -n moreother --no-capture-output python -c "import cv2,numpy,reportlab,fontTools,PIL; print('cv2',cv2.__version__); print('aruco', hasattr(cv2,'aruco')); import fontTools; print('fontTools', fontTools.version)"
```

`aruco` 必须打印 `True` —— 模板四角标记靠它识别。若 False，说明装成了 `opencv-python`，
重装 `opencv-contrib-python` 即可：

```bat
conda run -n moreother --no-capture-output uv pip install --force-reinstall --index-url https://pypi.tuna.tsinghua.edu.cn/simple opencv-contrib-python
```

## 二、potrace（矢量化，只在跑 04 那台机器上需要）

推荐放在**远程 Linux** 上跑 04，一条命令装好：

```bash
sudo apt install -y potrace          # Debian / Ubuntu
sudo yum install -y potrace          # CentOS / RHEL
conda install -y -c conda-forge potrace   # 无 root 时用这个
```

Windows 上若坚持跑 04：`winget install potrace` 或 `choco install potrace`。
**没有 potrace 也能跑**，会自动退化成 OpenCV 轮廓提取，缺点是笔画边缘偏硬（直线段、无贝塞尔平滑）。
正式出片建议一定要装 potrace。

## 三、关于 NVIDIA GPU

**这条流水线用不上 GPU。** 全部是 CPU 侧的确定性图像处理：透视矫正、阈值化、轮廓提取、
贝塞尔拟合、字体表组装。3000 个字在普通 4 核 CPU 上大约 3–8 分钟。

只有当你后续想加这些能力时，CUDA 才有意义：

- 手写笔画断裂的深度学习补全（如基于 diffusion 的修复）
- 复杂背景（格子纸、纹理桌面）的笔迹分割
- 用少量样本做字形风格迁移，自动补全没写的字

到那时再装（注意按你实际的 CUDA 版本选 index）：

```bat
conda run -n moreother --no-capture-output uv pip install --index-url https://pypi.tuna.tsinghua.edu.cn/simple torch torchvision --index-url https://download.pytorch.org/whl/cu121
```

v1 不要装，纯属浪费时间和磁盘。
